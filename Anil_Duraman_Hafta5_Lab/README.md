## Çalıştırma

Python 3.10+ ve pytest gereklidir.

```bash
python -m pip install pytest
python -m pytest
```

Ödev, Hafta 4 uzay oyunu deposu verilmediği için bağımsız ve örnek bir proje olarak düzenlenmiştir. Mevcut Hafta 4 kodunuz varsa ilgili örnek fonksiyonları ve `travel()` akışını o projeye uyarlayın.

## İçerik

- `uzay_oyunu/dekoratorler.py`: `sure_olc`, `say`, `log_cagri`, `sinirla`, `hafiza`
- `uzay_oyunu/komutlar.py`: komut kayıt dekoratörü ve `yardim`, `envanter`, `harita`
- `uzay_oyunu/oyun.py`: örnek oyun fonksiyonları ve komut/gezegen seçimi
- `tests/`: dekoratör ve komut testleri
- `dekorator_sirasi.md`: Fibonacci çağrı sayıları ve dekoratör sırası açıklaması
